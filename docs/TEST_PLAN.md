# План тестування та результати

## Автоматичні тести (JVM, запускаються в CI: `./gradlew test`)

| Модуль | Що перевіряється |
|---|---|
| `core:protocol` | Hex, CRC-16/MODBUS (еталон NT Link), JSON-екранування, `StreamBuffer` |
| `core:diagnostics` | знеособлення MAC, вміст JSON-звіту |
| `core:devices` | рівні підтримки, бар’єр Experimental, `CommandExecutor` (тайм-аут, підтвердження, відмова guard, закритий канал), Fast Pair, злиття заряду, каталог і нормалізація назв, `ReconnectPolicy`, вибір драйвера |
| `drivers:jbl` | кадри H-AA на еталонних байтах TUNE230NC, P4 GET/TLV, RACE, guard (factory reset, P4 SET, чужі кадри), повний цикл сесії з фейковим `DeviceLink` |
| `drivers:sony` | кодування/декодування з escape, checksum, ACK, NC v2/v1 |
| `drivers:nothing` | CRC на еталонному кадрі, заряд, режими, allowlist |
| `drivers:xiaomi` | кадри GAIA, заборона значення 0x04 |
| `drivers:apple` | парсер proximity-оголошення |
| `core:database` | історія заряду, прогноз автономності, кодеки профілів |

Результати останнього прогону — у CI (артефакт `test-reports`) та в розділі «Результати» нижче.

## Ручне тестування на JBL Tune Beam 3 (власник проєкту)

1. Встановити `SonicControl-debug.apk`, надати дозвіл «Пристрої поблизу».
2. Підключити навушники в Android. «Пристрої» → вибрати Tune Beam 3.
   Очікування: драйвер JBL, модель «JBL Tune Beam 3», статус Connected.
3. «Головна»: чи з’явився заряд і з якого джерела (Fast Pair / BAS)? Порівняти з офіційним застосунком.
4. «Лабораторія → Діагностика»: «Сканувати сервіси», «Прочитати все». Записати, чи є сервіс `65786365-…` (Harman) і записи SDP (особливо `…0099-aabbccddeeff`).
5. Під час відкритої Лабораторії натиснути сенсор навушника (перемикання ANC). Чи з’явилися RX-кадри в журналі?
6. Налаштування → Експериментальні функції → увімкнути. Lab → «Визначити протокол».
7. «Експорт JSON» і надіслати файл для аналізу.
8. Якщо протокол визначено як H-AA або RACE: «Звук → Шум», перемкнути режими; перевірити на слух і за відповіддю.
9. Вимкнути/увімкнути навушники — перевірити автоматичне відновлення.

Офіційний застосунок JBL під час тесту має бути закритий.
